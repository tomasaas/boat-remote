Ikke tilkoblet

Får ikke kontakt med båten

VPS-en er oppe, men båten svarer ikke. Siden sjekker hvert 5. sekund og viser GUI-en når båten svarer igjen.

Bruk SSH for å feilsøke: logg inn på VPS-en, og derfra videre til Pi-en gjennom tunnelen.

1. Får du kontakt med Pi-en over SSH?

På VPS-en:

ssh admin@10.88.0.2

Tunnelen eller Pi-en er nede

Har Pi-en strøm? Har den nett (WiFi eller mobil)? Se når siste håndtrykk var, på VPS-en:

sudo wg show

Er det mer enn 3 minutter siden, er det Pi-en som ikke kommer ut på nett.

2. Kjører appen?

systemctl status boat

Appen har stoppet

Se feilmeldingen:

journalctl -u boat -n 50

Start igjen:

sudo systemctl restart boat

3. Svarer den lokalt?

curl localhost:8000

Appen henger

Start den på nytt:

sudo systemctl restart boat

4. Har du endret .py-filer siden siste omstart?

Koden og siden er i utakt

Start på nytt, og sjekk deretter config.json.

sudo systemctl restart boat

5. Viser denne noe annet enn throttled=0x0?

vcgencmd get_throttled

Underspenning

Strømforsyningen eller batteriet er for svakt.
